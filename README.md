# Instagram-replica
Instagram like webpage that fetches data from your server

in this specific project i want to fetch data from Instagram in order to save it in my server and view the data more easily 

the template for the intsagram website is from [ZinebEsso](https://github.com/ZinebEsso/instagram_clone)
# building materials
i want to keep it simple as possible so
python - http.server with jinja2 to make a behavior like flask render-template(had problems with flask in the past)
